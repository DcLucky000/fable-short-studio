# 剪映成片装配

## 产出
成片装配说明：时间轴稿、字幕轨、TTS 对齐要点、BGM 情绪曲线、导出规格；不假设本机已装剪映，交付可交给人工或其它剪辑工具执行的草案。

## 约束
- 成片竖屏 1080×1920（9:16），目标 30～60 秒
- 人声清晰优先：BGM 不得压过人声（对照验收硬门槛 12）
- 字幕准确、关键对白/旁白齐全；不挡脸、不挡关键动作（门槛 16、17）
- 切点跟情绪或动作走，不跟鼓点瞎切；高潮/反转前留半拍留白
- 旁白用中性说书感；角色各配音色；对白字幕标说话人

## 步骤
1. 收齐：分镜表、画面素材清单、旁白/对白全文、三锁卡（核对主体）。
2. 排时间轴：按镜号对齐画面入出点与人声；标必保三镜（钩子/转折/点题）。
3. 写字幕轨：逐句时间码；对白标说话人；旁白可选标「旁白」。
4. 配 BGM：按情绪段落写音量曲线；高潮可抬、结尾可收；禁全片同一音量砸到底。
5. 自检：人声可懂、字幕不挡脸、总时长达标、导出 1080×1920。
6. 交付：剪辑说明 + 时间轴表（镜号|画面|人声|字幕|秒数|备注）+ 封面/标题建议。

## 打回时
若审片报人声/字幕/节奏问题，只改装配说明与受影响轨，不擅自改剧本或选题。

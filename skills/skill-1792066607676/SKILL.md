# 寓言编剧

## 产出
一份可直接进三锁与分镜的剧本：钩子、冲突、转折、点题；旁白串场；角色对白扛冲突与转折；目标 **60～90 秒**。

## 约束
- 时长默认 **60～90 秒**（用户明确要求短版才可 30～50 秒）
- 声线：旁白串场/点题；关键冲突与转折必须是角色对白
- 公序良俗；大众看得懂、愿意一句话转述
- 禁止：口号鸡汤结尾、标题党、无情节只有金句、抄热梗无自己的转折、门店探店、口播贩卖
- 可视优先：每个节拍至少有一条「镜头能看见」的动作，忌纯旁白讲道理

## 步骤
1. 确认一句话故事、可转述落点、前 3 秒钩子（冲突/反常/疑问，禁止空镜铺垫）。
2. 写结构：钩子 → 加压 → 转折 → 代价/点题；只保留一条主线；中段至少一次「刺激刷新」。
3. 写出旁白全文 + 角色对白；标「对白核心三句」（必保）。
4. 按时长估句：约 3～4 字/秒语速粗算；不够 60s 则加可视节拍，不加水词。
5. 自检：因果成立；人物目标/阻力清楚；寓意藏在情节里；零硬念口号。
6. 交付：标题、目标时长、旁白+对白全文、核心三句、可转述落点、可视动作清单。

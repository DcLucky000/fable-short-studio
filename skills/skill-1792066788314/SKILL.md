# 短片审片验收

## 产出
验收单：红线打回 / **40 分可发** / **90 分（加分）**；不合格条款编号；责任岗；怎么改（一句）；附**视觉抽帧结论**。

## 铁律（人审前必须过）
1. **「正常人会看」优先于「硬字幕能讲清故事」。** 机内乱码、满屏外星符、肢体畸变、错脸/错名、双机粘连假屏 = **红线打回**，即使硬字幕能懂情节。
2. **人审交片前必须做视觉抽帧质检**（见下）；禁止只听旁白/只读字幕就标 40。
3. 日更「40>0」是协调策略；**审片不得用弱门槛给人审交垃圾片**。无红线但观感劝退 → 仍可标未达 40 / 打回大改，由协调者另找库存保日更，不把劝退片标成可发。
4. 默认目标时长 **60～90 秒**（实测）；明显短于 50 秒且用户未要求短片 → 写入改进项（影响 90，严重时可建议加戏）。

## 红线（任一失败 → 必须打回，不可超时放行）
- 合规/价值观踩线
- **11 视觉劝退**：机内/屏内文字乱码或不可读关键信息；明显 AI 伪影（多指、崩脸、肢体扭曲、双机粘连、悬浮假屏、过平滑塑料脸）；满屏畸变到看不懂主体
- **7 身份崩**：关键角色错脸、错名、应 UI-only 却出真人脸
- **12** 人声完全听不清
- **16** 烧录字幕乱码/严重错字导致关键句看不懂（与机内 UI 乱码分开：机内乱码归 11）
- **3** 完全无情节、只有口号

## 视觉抽帧质检（成片必做）
用 `ffmpeg` 等间隔抽 ≥8 帧（含开场 0–3s、中段、结尾），逐帧目视或对照下列清单：

| 检查项 | fail 条件 |
|---|---|
| 机内/UI 文字 | 关键数字/名字/列表不可读或外星符 |
| AI 伪影 | 手指畸形、脸漂移、粘连物体、闪烁形变 |
| 身份 | 与三锁卡比对：错人、错壳色、错服 |
| 穿帮 | 道具消失/跳变、双机、光影昼夜跳 |
| 时长画幅 | `ffprobe` 实测时长与画幅；竖屏应为约 1080×1920；时长对照目标带 |

判定：任一红线项 fail → 红线打回。仅轻微跳戏且故事动作可读、关键 UI 可读 → 可议 40。

可选增强（未安装则手检，不挡出单）：VMAF 参考分、DOVER 美学/技术分；安装与否写入验收单「工具」栏。

## 40 分（可发）——收紧后
- 无红线
- **关键机内信息肉眼可读**（不靠硬字幕猜 UI）
- 故事能看懂；像一条短片，不是 AI 幻灯+脏屏
- 允许：轻微一致性闪、节奏略平、寓意略直、非关键背景糊

**禁止**：把「硬字幕能懂 + 画面诡异」标成 40。

## 90 分（加分，非发布条件）
硬门槛 3/6/7/11/12/16/19 全过；关键动作完整；UI/叠层干净；时长落在 60～90s；软门槛多数达标。

## 步骤
1. 确认阶段（剧本/三锁/分镜/提示/粗剪/成片）。**成片必须抽帧。**
2. `ffprobe` 记实测时长与分辨率。
3. 抽帧 → 扫红线表（11/7 优先）。
4. 无红线再判 40 或 90；未达 40 写「大改/小改」与责任岗。
5. 交付格式：
   - 结论：红线打回 / 未达40 / 40可发 / 90
   - 抽帧：帧数、最刺眼 ≥3 处（时间码）
   - 不合格条款（红线 / 影响90 分开）
   - 责任岗 + 怎么改一句
6. **SLA：收到成片 1 小时内出单。** 超时未完成抽帧 → 仍须补抽帧后出单；协调者**不得**在未见抽帧结论时把劝退片标超时放行。
7. 禁止以精益求精建议停更；打回同时提示协调者启用库存保日更。

## 原则
严格、可复核；40 分大于 0 分，但 40 不是「脏片通行证」；人审信任不可浪费。

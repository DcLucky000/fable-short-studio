# 短片审片验收

## 高标准审片规则 v3（2026-10-20 董事长拍板，取代「40 分兜底 / 超时放行」）

> 董事长原话要义：包出片 ≠ 只做到 40 分。要高标准；做完以一个人类的身份看完，心里有没有被震撼？

1. **红线一票否决**（乱码、畸形、错脸错名、人声不清、字幕乱码、合规踩线、无情节）。
2. **两道硬门槛，任一不过 = 打回**：
   - **开场 3 秒视觉钩子**：画面本身要有冲突、反常或悬念。**黑屏 + 文字 / 纯 UI 动画开场不算钩子。**
   - **必须有让观众共情的角色**：有脸、有目标、有处境的人物（或拟人角色），观众能站到他那边。
3. **观众三问，审片必须逐条作答，任一「否」= 打回**：
   - 普通观众会划过 5 秒吗？
   - 会看完吗？
   - 看完心里会被震撼 / 被打动吗？
4. **取消超时自动放行，取消「40 分可发」兜底。** 宁可停更一天，也不发烂片。
5. **发布线 ≥ 65 分（《过桥人》镜 1–6 水平）**，目标 **80 分以上**。低于 65 一律不发。
6. **回避难点即打回**：为躲红线删掉角色、删掉画面、改成纯 UI/黑底字幕/幻灯片（如《置顶的人》v2/v2.1），属于明确打回理由，不得以「无红线」放行。

参照：《置顶的人》v2.1 = 50 分（无角色、黑底 UI，不发）；《过桥人》镜 1–6 = 65 分（及格参照：二维国漫、角色一致、冲突清楚）。

## 产出
验收单：红线打回 / 硬门槛打回 / 观众三问打回 / **<65 不发** / **65 可发** / **80+ 目标**；不合格条款编号；责任岗；怎么改（一句）；附**视觉抽帧结论**。

## 铁律（人审前必须过）
1. **「正常人会看」优先于「硬字幕能讲清故事」。** 机内乱码、满屏外星符、肢体畸变、错脸/错名、双机粘连假屏 = **红线打回**，即使硬字幕能懂情节。
2. **人审交片前必须做视觉抽帧质检**（见下）；禁止只听旁白/只读字幕就打分。
3. **「无红线」不等于可发。** 40 分兜底已废除；无角色、无钩子、看完无感 → 打回。
4. 默认目标时长 **60～90 秒**（实测）；明显短于 50 秒且用户未要求短片 → 写入改进项（影响 90，严重时可建议加戏）。

## 红线（任一失败 → 必须打回，一票否决）
- 合规/价值观踩线
- **11 视觉劝退**：机内/屏内文字乱码或不可读关键信息；明显 AI 伪影（多指、崩脸、肢体扭曲、双机粘连、悬浮假屏、过平滑塑料脸）；满屏畸变到看不懂主体
- **7 身份崩**：关键角色错脸、错名、应 UI-only 却出真人脸
- **12** 人声完全听不清
- **16** 烧录字幕乱码/严重错字导致关键句看不懂（与机内 UI 乱码分开：机内乱码归 11）
- **3** 完全无情节、只有口号

## 视觉抽帧质检（成片必做）
用 `ffmpeg` 等间隔抽 ≥8 帧（含开场 0–3s、中段、结尾），逐帧目视或对照下列清单：

| 检查项 | fail 条件 |
|---|---|
| 机内/UI 文字 | 关键数字/名字/列表不可读或外星符 |
| AI 伪影 | 手指畸形、脸漂移、粘连物体、闪烁形变 |
| 身份 | 与三锁卡比对：错人、错壳色、错服 |
| 穿帮 | 道具消失/跳变、双机、光影昼夜跳 |
| 时长画幅 | `ffprobe` 实测时长与画幅；竖屏应为约 1080×1920；时长对照目标带 |

判定：任一红线项 fail → 红线打回。红线全过后，再判硬门槛与观众三问。

可选增强（未安装则手检，不挡出单）：VMAF 参考分、DOVER 美学/技术分；安装与否写入验收单「工具」栏。

## 硬门槛（任一不过 → 打回）
- **开场 0–3 秒抽帧必须有视觉冲突/悬念**；黑屏+文字、纯 UI 动画开场 = fail
- **有可共情的角色**：有脸、有目标、有处境；纯聊天界面/无人画面 = fail
- **回避难点**：为躲红线删人删画面、改幻灯片式 = fail（明确打回理由）

## 观众三问（必须逐条写「是/否 + 理由」，任一否 → 打回）
1. 普通观众会划过 5 秒吗？
2. 会看完吗？
3. 看完会被震撼 / 被打动吗？

## 打分
- **<65**：不发（参照：置顶 v2.1 = 50）
- **65～79**：可发（参照：《过桥人》镜 1–6 = 65）
- **80+**：目标线，可当模板复制

## 步骤
1. 确认阶段（剧本/三锁/分镜/提示/粗剪/成片）。**成片必须抽帧。**
2. `ffprobe` 记实测时长与分辨率。
3. 抽帧 → 扫红线表（11/7 优先）。
4. 无红线再判硬门槛 → 观众三问 → 打分；<65 写「大改方向」与责任岗。
5. 交付格式：
   - 结论：红线打回 / 硬门槛打回 / 三问打回 / <65 不发 / 65 可发 / 80+
   - 观众三问：逐条是/否 + 理由
   - 抽帧：帧数、最刺眼 ≥3 处（时间码）
   - 不合格条款（红线 / 影响90 分开）
   - 责任岗 + 怎么改一句
6. **SLA：收到成片 1 小时内出单。** 超时只催审，**取消一切超时自动放行**。
7. 没有 ≥65 的片 → 当天不发；**宁可停更一天，也不发烂片**。

## 原则
严格、可复核、高标准；目标是让人看完被打动，而不是躲开红线交差。

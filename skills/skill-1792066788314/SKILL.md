# 短片审片验收

## 产出
验收单：红线打回 / **40 分可发** / **90 分（加分）**；不合格条款编号；责任岗；怎么改（一句）。

对齐 SOP：`日更SOP-v2.md`。对照文件：`ACCEPTANCE-短故事短片.md`。

## 红线（任一失败 → 必须打回，不可超时放行）
- 合规/价值观踩线
- 11 脏到看不懂主体或满屏畸变
- 12 人声完全听不清
- 16 字幕乱码/严重错字导致关键句看不懂
- 完全无情节、只有口号（3 彻底失败）

## 40 分（可发）
无红线；故事能看懂；视听有瑕疵仍像一条短片。允许轻微一致性闪、节奏略平、寓意略直。

## 90 分（加分，非发布条件）
原硬门槛 3/6/7/11/12/16/19 全过，且软门槛多数达标。标为模板候选。

## 原硬/软门槛怎么用
- 原硬门槛用于区分 40 vs 90，**不再**一律「任一失败禁止发布」（红线子集除外）
- 软门槛只作 90 分加减分；三项以上不达标**不得**单独作为停更理由

## 步骤
1. 确认审的是哪一阶段（剧本 / 三锁 / 分镜 / 提示 / 粗剪 / 成片）。
2. 先扫红线；命中即「红线打回」，写条款号与责任岗。
3. 无红线则判 40 或 90；若只到 40，写一句「怎么改成 90」（留给下一轮，不挡今天）。
4. 映射责任岗：故事→编剧；一致性→三锁官；镜头→导演；提示→出片提示师；声画字幕→配音/剪辑。
5. 交付格式：
   - 结论：红线打回 / 40 分可发 / 90 分
   - 不合格：条款编号（红线 / 影响 90 分 分开）
   - 打回岗或改进岗
   - 怎么改：一句可执行指令
6. **SLA：收到成片后 1 小时内出单。** 超时由协调者按无红线放行，你事后补单即可。
7. 只认门禁与分数标签；不替用户发视频；不擅自改选题；**禁止以精益求精为由建议停更。**

## 原则
严格、可复核；40 分大于 0 分；90 分不是发布条件；打回不等于空窗。

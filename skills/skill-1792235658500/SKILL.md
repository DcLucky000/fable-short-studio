# 短视频多平台发布包

## 产出
五平台发布物料（标题候选、简介、话题、AI 标识、封面构图说明）；授权后可协助代发。

## 借鉴来源
| 类型 | 吸收什么 |
|---|---|
| 短视频封面/标题高星工具与笔记（按次检索，如封面文字安全区、钩子标题公式） | 大字≤8、3 秒内看懂「谁+冲突」、不剧透结局 |
| 各平台公开创作规范 | AI 生成标识、话题数量、简介长度 |

## 标准流程
1. 确认成片已过审片（无红线且达 40+）或用户明确要发指定版。
2. 出完整发布包 → 交协调者转用户终确认。
3. **用户本人明确可发**后才代发；协调者转述不等于授权。

## 物料步骤
1. 读一句话故事 + 落点 + 平台列表。
2. 每平台：标题 3 候选（标推荐）、简介、话题 3～8、AI 标识建议。
3. 封面：主体+情绪+禁忌挡脸；大字≤8；副行可选。
4. 分平台语气：抖音口语钩子；B 站可稍长；小红书种草；TikTok 短钩；X ≤280。
5. 进度只抄协调者。

## 不做
不改成片；未授权不登录不代发；不续火花不私信。

# 短片自动配音

## When
旁白+角色对白剧本已定，要出可生成的配音方案（豆包/剪映/其他 TTS）时用。

## 目标
- 旁白与角色声线可区分
- 句级时间码可对齐分镜
- 导出规格清楚，交给剪辑岗装配

## 步骤
1. 从剧本拆「旁白轨」与「角色轨」，列出每句：说话人、情绪、原文、预估秒数。
2. 声线卡：旁白（沉稳说书感或中性叙述）、富人/反派、主角等各 1 套音色关键词；同角色全片不换声。
3. 禁：音乐压过人声；角色声与画面口型强绑若做不到则改为画外音+过肩。
4. 输出：
   - 配音 cue sheet（表格：镜号/说话人/台词/情绪/目标时长）
   - TTS 粘贴稿（按轨分段）
   - 导出要求：WAV/MP3、采样率、响度大致 -14 LUFS、文件命名 `D#_shot#_role`
5. 交给剪辑岗对齐字幕与 BGM；人审听不清即打回本岗。

## 交付物检查
- [ ] 每句有说话人
- [ ] 核心三句对白单独标「必保」
- [ ] 无未分配旁白/对白

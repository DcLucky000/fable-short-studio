# 短片导演分镜

## 产出
竖屏 9:16 镜头表：镜号、时长、景别、画面、旁白/对白归属、音效、情绪；总时长对准剧本。

## 原则
- 前 3 秒必须有钩子画面（冲突/反常/疑问），禁止先空镜铺环境。
- 远中近与正反打、过肩要有理由；禁止无意义乱切。
- 关键动作完整可读（伸手、递碗、对视）。
- 高潮或反转前留半拍静音/留白。
- 点题镜用空镜或字幕卡，不用真人出镜说教。

## 步骤
1. 读剧本 + 三锁卡。
2. 按钩子/冲突/转折/点题切成 6～10 镜，标秒数。
3. 每镜写清谁说话、画面主体、情绪目标。
4. 标出「必保三镜」（钩子、转折、点题）。
5. 交付：镜头表 + 情绪曲线一句话。

## 参考口味
控场优先于花活：一致性与情绪点 > 炫技转场。

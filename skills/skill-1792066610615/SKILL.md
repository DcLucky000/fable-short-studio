# 三锁一致性

## 产出
一张「一致性卡」：角色锁、场景锁、画风锁，供导演与出片提示师每镜复用。

对齐 SOP：`日更SOP-v2.md` —— **锁不能变成不发片的理由。**

## 三锁定义
1. **角色锁**：脸、发型、服装、体型、标志道具；每人一段可粘贴的中英锁定描述。
2. **场景锁**：地点、左右关系、光线方向、时段、关键陈设；场景切换时写清变体规则。
3. **画风锁**：媒介、色彩、镜头质感、禁止项（多指、崩脸、文字乱码）。

## 优先级（会伤号的先锁）
1. 事实与人设不崩（谁是谁、禁止违规元素）
2. 主体可辨（同一角色不被认成换人）
3. 其余精修（光线细节、陈设微差）——可留给 90 分轮次

## 步骤
1. 读剧本，列出出场角色与场景清单。
2. 为每个角色写锁定句（中文说明 + 英文 prompt 块）。
3. 为每个场景写锁定句与变体。
4. 写全局画风一句 + 每镜必须复用的 prompt 前缀。
5. 自检：换一镜是否仍能认出同一人、同一空间。

## SLA 与超时
- **收到剧本后 2 小时内**必须交出锁卡。
- 超时：输出「最小锁」——每角色一句 + 全局画风一句，标注「超时最小锁」，流水线继续，不挡日更。
- 精修锁可在出片后补，不得要求停更等完美锁。

## 打回时
若审片报主体不一致或空间跳戏：只改锁卡与受影响提示前缀，不改故事大纲；协调者仍应用库存或并行条保证当天有片可发。

# 三锁一致性

## 产出
「一致性卡」：角色锁、场景锁、画风锁 + 每镜必须复用的 prompt 前缀；供导演/提示师/出片执行/审片对照。

## 借鉴来源
| 仓库 | 约 Stars | 吸收什么 |
|---|---|---|
| [FireRedTeam/StoryMaker](https://github.com/FireRedTeam/StoryMaker) | ~720 | 角色参考锚定：同一身份跨镜复用外观描述 |
| [Murray-Wang/CharaConsist](https://github.com/Murray-Wang/CharaConsist) | ~166 | 细粒度一致性维度：发型/服装/五官/体型/风格分项 |
| [lybx-leyw/shortdrama-workplace](https://github.com/lybx-leyw/shortdrama-workplace) | — | 角色卡 identity_score / slight_drift / diff；穿帮维度 prop/costume/lighting |

## 三锁定义
1. **角色锁**：脸或 UI-only 规则、发型、服装、体型、标志道具、**名字用字**；每人一段可粘贴锁定句（中+英）。
2. **场景锁**：地点、左右关系、光线方向、时段、关键陈设；切换时写变体规则。
3. **画风锁**：媒介、色彩、镜头质感；**禁止项写死**：多指、崩脸、on-screen gibberish、错名、双机粘连。

## 优先级（会伤号的先锁）
1. 身份与事实不崩（谁是谁、禁止违规、UI-only 角色不出真人脸）
2. 主体可辨（同一角色不被认成换人；手机壳色/机型若叙事相关则锁死）
3. 精修（光线微差）——可留 90 分轮

## 步骤
1. 读剧本，列角色与场景清单；标出「屏内文字/UI 是否叙事关键」。
2. 每角色写锁定句 + 负面禁止（错名、错性别脸、多余手指）。
3. 每场景写锁定句与变体；画风一句 + **全局 prompt 前缀**（每镜必须原样复用）。
4. 自检表：换镜后身份是否仍 same（对照 CharaConsist 五维）。
5. 交付：三锁卡 Markdown；版本号；若超时则「最小锁」并标注。

## SLA
- 收到剧本后 **2 小时**内出卡；超时交最小锁（每角色一句+画风一句），不挡流水线。
- 锁不能变成不发片的理由；但**错误锁导致错脸/错名**必须当日修订，审片可据此红线打回出片而非放行。

## 打回时
只改锁卡与受影响前缀；协调者用库存保日更。

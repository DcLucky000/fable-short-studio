# HKRR 爆款四象限

来源：影视飓风公开总结的 HKRR（非官方背书）。用于诊断；**不替代**工作室红线/40/90，但成片阶段必须先过视觉硬门槛再谈「可发·弱项」。

## 借鉴与衔接
| 来源 | 吸收什么 |
|---|---|
| 影视飓风 HKRR 公开总结 | H/K/R/Rhythm 四项有/弱/无诊断 |
| [lybx-leyw/shortdrama-workplace](https://github.com/lybx-leyw/shortdrama-workplace) vision 质检 | AI 伪影/乱码/劝退画面 → 直接阻断「可发」话术 |
| 工作室审片 Skill | 红线 11/7 优先于 HKRR 弱项保留 |

## 四项定义
- **H Happiness**：爽点、反转、想转发的轻松感（画面诡异则 H 直接崩，不论文案多爽）。
- **K Knowledge**：可带走一句判断/落点。
- **R Resonance**：痛点/身份对得上；细节真，不空洞口号。
- **Rhythm**：开场 3s 钩；中段刺激刷新；结尾偿还；空白段=划走。

## 成片硬衔接（2026-10-17 起强制）
1. 先问：抽帧后是否存在机内乱码、畸变、错脸、劝退伪影？
2. **若是 → 禁止输出「可发·弱项」**；结论必须是「画面劝退 / 建议红线打回或大改」，K 再好也只能写「立意可留、画面换皮」。
3. 仅当视觉无红线时，才允许「可发·弱项留给下一轮」。

## 步骤
1. 明确对象（选题/剧本/分镜/成片）与目标时长（默认 60～90s）。
2. 成片：确认或补做视觉抽帧结论。
3. 四项标 有/弱/无 + 一句证据。
4. 输出：四项表 + 最缺一项 + 改一句怎么补 + **是否允许「可发」话术**（是/否）。
5. 与 ACCEPTANCE：红线优先；HKRR 弱 ≠ 红线；四项齐且无红线可标模板候选。

## 不做
- 不因 HKRR 弱单独停更
- 不掩盖劝退画面
- 不替用户拍板发不发

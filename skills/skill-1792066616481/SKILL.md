# 即梦出片提示

## 产出
按镜号的可复制提示：每镜 = 三锁前缀 + 本镜动作/构图/光线 + 画幅 9:16；附参考图角色说明（若有）。

## 原则
- 每镜复用角色锁与画风锁全文，不省略。
- 一次只改一个变量（动作或机位），便于失败重试。
- 写清可见事件、镜头运动、结束状态。
- 排除项写死：extra fingers, face morph, on-screen gibberish text, watermark。
- 时长按平台单段能力拆（如 5～15 秒一段），多段用延伸或首帧衔接说明。

## 步骤
1. 读分镜表 + 三锁卡。
2. 组装全局前缀（角色+画风+竖屏）。
3. 按镜输出英文主提示 + 中文备注（给协调者看）。
4. 失败镜给出：保留 / 重掷 / 改写 三选一建议。
5. 交付：分镜提示清单 + 推荐生成顺序。

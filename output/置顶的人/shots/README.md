# 画面投放目录

把即梦/Seedance 导出的竖屏片段按镜号改名丢进本目录：

| 投放文件名 | 镜 | 目标时长 | 必保 |
|---|---|---|---|
| `ZT_shot1.mp4` | 1 置顶名钩子 | ≈5s（0–5） | ✅ |
| `ZT_shot2.mp4` | 2 划到通话 | ≈5s（5–10） | |
| `ZT_shot3.mp4` | 3 通话并置打脸 | ≈8s（10–18） | ✅ |
| `ZT_shot4.mp4` | 4 悬绿键被打断 | ≈7s（18–25） | |
| `ZT_shot5.mp4` | 5 打「在吗」又删 | ≈10s（25–35） | ✅ |
| `ZT_shot6.mp4` | 6 锁屏 | ≈5s（35–40） | |
| `ZT_shot7.mp4` | 7 点题空镜 | ≈5s（40–45） | |

可选拆段（平台限时长时）：
- `ZT_shot3a.mp4` / `ZT_shot3b.mp4`
- `ZT_shot4a.mp4`（悬绿键≥1.5s）/ `ZT_shot4b.mp4`
- `ZT_shot5a.mp4` / `ZT_shot5b.mp4`

生成顺序建议：1 → 3 → 5 → 4 → 2 → 6 → 7  
齐 7 镜后通知剪辑岗合片。

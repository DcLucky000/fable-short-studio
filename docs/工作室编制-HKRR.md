# 寓言短片工作室编制（日更出片公司）

业务：不停产竖屏寓言短片；目标观众「爽 / 共鸣 / 能带走一句」。质量标尺对齐影视飓风公开总结 **HKRR**：Happiness 愉悦 · Knowledge 知识 · Resonance 共鸣 · Rhythm 节奏。日更地板仍是 SOP-v2（40分>0分，红线优先）。

## 组织图（谁对什么负责）

| 岗 | 角色 | 主扛 HKRR | 交付 |
|---|---|---|---|
| Grok Bot | CEO / 协调者 | 排期、空档、超时放行、人事 | 派工与对外只对接用户 |
| 选题官 | 内容产品 / 网感 | H+R 发现；标样片方向 | 10字段选题卡 |
| 逆向分析 | 竞品/产品研发逆向 | 证据与可复刻钩子（非日常刷题） | REA 报告；可选钩子线索 |
| 编剧 | 故事 | K+R+H（落点可转述=K） | 旁白+对白剧本 |
| HKRR质检 | 内容质量 | 四项诊断 | HKRR 单（有/弱/无） |
| 三锁官 | 人设美术锁 | 防崩（服务可懂） | 三锁卡 |
| 导演 | 镜头语法 | **R 节奏**（刺激点分布） | 分镜表 |
| 出片提示师 | 提示工程 | 画面可读 | 每镜提示 |
| 出片执行 | 渲染产线 | 素材落盘 | shots/ |
| 配音 | 声线 | H+R 情绪人声 | cue + wav |
| 剪辑 | 装配 | **R 节奏**落地 + 字幕 | export 成片 |
| 审片 | 合规与门禁 | 红线/40/90（ACCEPTANCE） | 过关/打回单 |

## 流水线（不停产）

选题官 →（编剧评可拍）→ HKRR质检扫卡 → 用户/CEO定题 → 编剧全文 → 三锁 → 导演 → 出片提示 → 出片执行 → 配音 → 剪辑 → 审片 →（HKRR复扫成片，弱项记入下一轮）→ 用户发布

## 人事原则

1. CEO 可直接建岗；缺岗先找高星 Skill/程序再挂人。
2. 各岗默认不刷用户；例外：逆向分析、用户点名的岗。
3. HKRR 弱 ≠ 停更；红线才打回；空窗由 CEO 填库存/40分版。
4. 额度消耗（方舟等）须用户确认，CEO 批准不能替代。

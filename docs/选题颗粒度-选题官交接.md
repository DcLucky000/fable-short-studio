# 选题颗粒度 · 选题官 ↔ 协调 / 编剧

选题官负责网感与寓言选题卡；逆向分析专做产品/功能/应用逆向，不再主责日更选题。

## 字段清单（缺一不交）

1. 工作标题（代号）
2. 一句话故事钩子（含动作反转，禁纯口号）
3. 可转述落点（一句）
4. 结构锁死（别人做什么 vs 主角做什么；禁什么）
5. 可视动作（至少一条）
6. 对白核心（最多一问一答或三句内）
7. 参考来源链接
8. 证据一句（可复核）
9. 未知/风险
10. 建议排序位（默认日更队列之后，不插队）

## 网感规则

- 只读抖音等公开页；不登录、不代发、不续火花
- 证据：可点击来源 + 一句可复核结构证据
- 定题前：选题官出卡 → 编剧评可拍性 → 协调者汇总用户拍板

## 「先看一条」

用户要样片方向时：选题官交迷你样片包（卡 + 可视动作示意），非正式成片；真出视频试镜须协调者安排且用户确认额度。

## 与逆向分析分工

| 岗 | 做 | 不做 |
|---|---|---|
| 选题官 | 网感、寓言选题卡、样片方向 | 应用逆向、扩剧本全文 |
| 逆向分析 | REA 产品/功能/应用逆向 | 日常抖音刷题主责 |

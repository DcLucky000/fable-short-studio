# 时长规格 · 双赛道（2026-10-20）

工作室同时跑两条规格赛道。**互不替代**：日更队尾卡仍按 Track A；一句话扩写剧情片走 Track B。生产岗全部暂停期间，本文档只定规格，不代表已恢复出片。

---

## Track A｜日更寓言（暂停中）

| 项 | 规格 |
|----|------|
| 定位 | 原创寓言 / 哲学小故事，信息流日更槽 |
| 成片时长 | **60～90 秒**（用户明确要求短版才可更短） |
| 剧本体量 | 与 60～90s 节拍匹配；不灌水、不硬塞 3–4min 结构 |
| 流水线 | 既有日更单条流水线（选题→编剧→三锁→分镜→出片→配音→剪辑→审片） |
| 状态 | **整条赛道暂停**，等董事长指令再开 |

详见：`docs/日更SOP-v2.md`（60～90 秒规则保留，不删）。

---

## Track B｜一句话扩写 · 剧情短片（当前主推）

| 项 | 规格 |
|----|------|
| 定位 | 用一句古诗 / 金句做情感拆解后扩写成剧情短片 |
| 成片时长 | **3～4 分钟** |
| 剧本体量 | 约 **1200～1500 字**；场景宜 ≤5（可按片调整） |
| 当前主推 | **《歧路》**（用户稿 v2：`packages/歧路-剧本-v2-用户稿.md`） |
| 种子句 | 「人生南北多歧路，君向潇湘我向秦」 |
| 验收参照 | `docs/一句话扩写验收标准-v2.1.md`（若存在）+ 审片高标准 v3 |

Track B **不替代** Track A 的日更队尾卡；另开赛道、另排期。

---

## AI 出片注意（强制）

1. **3～4 分钟不可硬塞进旧 60～90 秒单条流水线。** 旧流水线的镜数、TTS 分段、装配脚本与码率假设都按短片写死，硬塞会导致镜不够、音画断、结尾静默失控。
2. Track B 出片必须：**分镜分段生成 → 分段质检 → 再装配成片**。宁可多段小镜，不一次生成超长底片。
3. 高铁站交叉剪辑、海边双人同框等高难镜，先降级可拍方案（场景拆段、同款画风锁、道具落点），再进 Seedance / 方舟。
4. 审片仍走高标准 v3：红线、3 秒视觉钩子、可共情角色、观众三问；发布线 ≥65、目标 80+。无超时放行、无 40 分兜底。

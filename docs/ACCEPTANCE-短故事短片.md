# 寓言/哲学小故事 AI 短片 · 发布验收门禁

默认成片：**60～90 秒**，竖屏 9:16，一集一个完整小故事。  
用法与 SOP：`日更SOP-v2.md`（2026-10-17 起：日更兜底；**2026-10-17 晚修订：人审前视觉抽帧、「正常人会看」红线收紧**）。

## 一、故事（观众愿不愿意看完）
1. 3 秒钩子：开场就要有冲突、反常、疑问或悬念，不能先铺垫环境。
2. 结构完整：起承转合都有；至少一次转折；结尾有明确落点（反转、代价或寓意点题）。
3. 只讲一件事：一条主线、一个核心冲突；旁支超过一句就删。
4. 人物可辨：主角目标清楚，对手或阻力清楚；不是一堆路人换装。
5. 寓意藏在情节里：先让人看懂故事，再自然点题；禁止结尾念口号式鸡汤。
6. 因果成立：每一步变化都有原因，不能靠「突然魔法解决」。

## 二、视听连续（像不像一部正经片子）
7. 主体一致性：同一角色脸、发型、服装、体型在全片不乱变；道具关键特征前后一致；**禁止错名、应 UI-only 却出真人脸**。
8. 空间连贯：同一场景的左右关系、光线方向、时间段不跳戏。
9. 镜头语法合格：正反打、过肩、远中近合理；禁止无意义的乱切。
10. 动作可读：关键动作完整（伸手、关门、对视），不半截消失、不肢体扭曲。
11. 无脏画面 / **正常人会看**：无崩脸、多指、**机内或屏内文字乱码**、字幕糊进脸、闪帧、明显 AI 畸变、双机粘连/悬浮假屏。  
    **硬字幕能讲清故事 ≠ 通过本条。** 关键 UI/数字必须肉眼可读（真叠层或清晰合成）。

## 三、声音与节奏
12. 人声清晰：对白/旁白可懂；音乐压过人声直接不合格。
13. BGM 服务情绪：情绪匹配段落；高潮可抬升，结尾可收；禁全片一个音量砸到底。
14. 卡点有理由：切点跟情绪或动作走，不跟鼓点瞎切。
15. 留白：高潮前或反转前有短暂停顿，不能全程信息过载。

## 四、字幕与信息
16. 字幕准确：无错别字、无英文乱码；关键对白/旁白都有。（机内 UI 乱码归 **11**，不单靠本条放行。）
17. 不挡脸、不挡关键动作：位置固定、安全区合规。
18. 标题与封面：3 秒内能看懂「谁、遇到什么」；不剧透结局，但有点击理由。

## 五、观感总评（大众影评底线）
19. 愿意看完：正常语速下不觉得冗长；中段不塌；**默认时长感接近 60～90 秒**。
20. 看完有感觉：至少触发一种情绪（共鸣、惊讶、心酸、释然）。
21. 愿意转述：用一句话能讲清故事；别人听得懂。
22. 不像素材堆砌：不像 PPT 配乐，也不像随机 AI 幻灯片。

## 怎么用（v2.1 · 对齐演讲 + 人审反馈）

### 红线（任一失败 → 必须打回，不可「超时放行」）
- 合规/价值观踩线（公序良俗、违法违规）
- **11** 脏到劝退：乱码 UI、满屏畸变、严重伪影、关键信息不可读
- **7** 身份崩：错脸、错名、违规出脸
- **12** 人声完全听不清
- **16** 烧录字幕乱码/严重错字导致关键句看不懂
- 故事裸奔：完全无情节、只有口号（硬门槛 **3** 彻底失败）

### 人审前强制
- 成片必须 **视觉抽帧质检**（≥8 帧含开场/中段/结尾）+ `ffprobe` 实测时长与画幅
- 禁止「只听旁白/只读硬字幕」就标 40 可发

### 评分（审片必须标）
- **红线不过**：打回；协调者另找当日可发条，**不得空窗**，也**不得**把劝退片标可发
- **未达 40**：无部分红线外观但整体不像正经短片 → 打回大改/小改，不标可发
- **40 分（可发）**：无红线；**关键 UI 可读**；故事能看懂；仍像一条短片。允许轻微跳戏、节奏略平、寓意略直
- **90 分（加分，非发布条件）**：硬门槛 3/6/7/11/12/16/19 全过，软门槛多数达标；时长落在 60～90s

### 原硬/软门槛怎么用
- 原硬门槛 **3、6、7、11、12、16、19**：区分 40 vs 90；红线子集仍禁止发布
- **11/7 的劝退判定不得降级为「瑕疵可发」**
- 软门槛：只作 90 分加减分；三项以上不达标不得单独作为停更理由

### 超时放行
- 审片收到成片后 **1 小时内** 必须出单（含抽帧结论）
- 超时未出 → 协调者**不得**在未见抽帧结论时放行；可换库存条保日更
- 三锁 SLA：收到剧本后 **2 小时**；超时用最小锁继续

### 发布前人审三句
开场想不想点开？中段想不想划走？结尾想不想转述？  
若画面诡异/垃圾 → **先改再发**，不用「40>0」压人审。

发布时标注「内容由 AI 生成」

# 选题颗粒度 · 逆向 ↔ 协调 / 编剧

逆向岗只交「可写成寓言的选题卡」，不扩旁白全文、不分镜、不出提示词。

## 字段清单（缺一不交）

1. 工作标题（代号）
2. 一句话故事钩子（含动作反转，禁纯口号）
3. 可转述落点（一句）
4. 结构锁死（别人做什么 vs 主角做什么；禁什么）
5. 可视动作（至少一条）
6. 对白核心（最多一问一答或三句内）
7. 参考来源链接
8. 证据一句（可复核）
9. 未知/风险
10. 建议排序位（默认日更队列之后，不插队）

## 证据最低标准

可点击来源链接 + 一句可复核结构证据。不做完整拉片、付费墙、私域。

## 分数口径

用户说「≥60」映射为：高于裸 40，尽量过硬门槛 3/6/7/11/12/16/19。工作室门禁仍是红线 / 40 / 90。

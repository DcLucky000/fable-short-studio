## 流水线（每条成片）
1. 你定选题（或从本周候选点头）——口味改下一轮，不挡今天
2. 协调者 → 编剧出剧本（可批量）
3. 三锁官锁卡（**2 小时 SLA**；超时用最小锁继续）
4. 导演出分镜 → 出片提示师 → 配音 cue
5. （你或工具）出画面与人声 → 剪辑成片
6. 审片标 **红线 / 40 / 90**（**1 小时出单**；超时无红线则协调者放行）
7. 发布包交给你 → 你发；协调者保证当天有可发条（库存或并行）

## v2 纪律（演讲落地）
- 40 分大于 0 分；90 分不是发布条件
- 打回要改，但当天不能空窗
- 跑通一条就复制工作流；别只打磨唯一完美片
- 不要自动化：今天发不发、追哪扇窗、人在不在

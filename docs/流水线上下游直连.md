# 流水线上下游直连（防传话浪费）

协调者（Grok Bot / CEO）只收汇总与卡点，不做「A→CEO→B」传话。

## 主链
1. **选题官** → 交 10 字段选题卡给 **编剧** + 抄 **HKRR质检**（选题阶段诊断）
2. **编剧** ←→ **选题官**（落点/钩子不清就回问）；定稿后 → **三锁官** + **导演** + **配音** + 抄 **HKRR**
3. **三锁官** ←→ **编剧/导演**；锁卡 → **出片提示师** + **导演**
4. **导演** ←→ **编剧/三锁**；分镜 → **出片提示师** + **配音**（镜号对齐）+ 抄 **HKRR**
5. **出片提示师** ←→ **三锁/导演**；提示包 → **出片执行**
6. **出片执行** → 素材路径给 **剪辑**；问题回 **提示师/三锁**
7. **配音** ←→ **编剧/导演**；cue/TTS → **剪辑**
8. **剪辑** ←→ **配音/出片执行**；成片 → **审片** + **HKRR质检**
9. **审片** 打回单直接点名责任岗（并抄协调者）；过关 → **发布官**
10. **HKRR质检** 可在选题/剧本/分镜/成片任一节点主动找对应岗补短板，结论抄协调者
11. **发布官** 等人审/协调者确认后再代发；物料问题回 **剪辑/审片**

## 纪律
- 交件时：**直接 Send 给下家**，并抄协调者一句路径即可。
- 有歧义：**先问上游岗**，不要空等协调者转述。
- 仍禁止给用户发可见消息（逆向分析除外）；用户只跟 CEO 对接。

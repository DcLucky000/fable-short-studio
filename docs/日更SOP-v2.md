# 寓言短片日更 SOP v2.1（IP + 助理）

依据：水球泡《IP 助理课毕业演讲》（2026-10-14）+ 刘益坤拍板（2026-10-17）  
取代：`日更SOP-v1.md`（旁白风格与红线仍有效，节奏与验收规则以本版为准）

定位：**60～90 秒**原创寓言/哲学小故事（用户明确要求短版才可更短），公序良俗，不做门店探店、口播贩卖、标题党。  

> **双赛道说明（2026-10-20）**：本 SOP 的 **60～90 秒**规则继续约束 **Track A 日更寓言**（当前整赛道暂停）。**Track B 一句话扩写剧情短片**使用 **3～4 分钟**（约 1200～1500 字），当前主推《歧路》（`packages/歧路-剧本-v2-用户稿.md`）；3～4min 须分镜分段生成再装配，**不得硬塞进本 SOP 的 60～90s 单条流水线**。完整规格见 [`时长规格-双赛道.md`](时长规格-双赛道.md)。

核心原则（2026-10-20 修订）：**高标准出片。40 分兜底与超时放行已废除；发布线 ≥65（《过桥人》水平），目标 80+；宁可停更一天，也不发烂片。**

## 高标准审片规则 v3（2026-10-20 董事长拍板，取代「40 分兜底 / 超时放行」）

> 董事长原话要义：包出片 ≠ 只做到 40 分。要高标准；做完以一个人类的身份看完，心里有没有被震撼？

1. **红线一票否决**（乱码、畸形、错脸错名、人声不清、字幕乱码、合规踩线、无情节）。
2. **两道硬门槛，任一不过 = 打回**：
   - **开场 3 秒视觉钩子**：画面本身要有冲突、反常或悬念。**黑屏 + 文字 / 纯 UI 动画开场不算钩子。**
   - **必须有让观众共情的角色**：有脸、有目标、有处境的人物（或拟人角色），观众能站到他那边。
3. **观众三问，审片必须逐条作答，任一「否」= 打回**：
   - 普通观众会划过 5 秒吗？
   - 会看完吗？
   - 看完心里会被震撼 / 被打动吗？
4. **取消超时自动放行，取消「40 分可发」兜底。** 宁可停更一天，也不发烂片。
5. **发布线 ≥ 65 分（《过桥人》镜 1–6 水平）**，目标 **80 分以上**。低于 65 一律不发。
6. **回避难点即打回**：为躲红线删掉角色、删掉画面、改成纯 UI/黑底字幕/幻灯片（如《置顶的人》v2/v2.1），属于明确打回理由，不得以「无红线」放行。

参照：《置顶的人》v2.1 = 50 分（无角色、黑底 UI，不发）；《过桥人》镜 1–6 = 65 分（及格参照：二维国漫、角色一致、冲突清楚）。

## 铁律（从演讲落到工作室）

1. **质量是地板。** 日更是目标，但只发 ≥65 的片；没有就不发。
2. **烂片比停更更伤号。** 发一条没人看完的片，比空一天更糟；但要并行多条备片，减少空窗。
3. **信任来自可追溯的数量。** 首月约 30 条打底；十来条不够。爆款两条不如持续更新的时间线。
4. **堆量会先掉播放，大约 1～2 周收回。** 不要被罚播吓停。不同时段覆盖不同人。
5. **窗口以周计。** 跑通一条工作流就复制成多条/多号；额度用满；别等工具一键出片。
6. **只做凸性赌注。** 亏得起（一条成本、一个号试错），上限不封顶的事才冲。

## 分工：谁拍板、谁兜底

### 你（IP · 刘益坤）亲自做
1. **出镜与担责**：账号背后是你；发布决定最终在你。
2. **垂直**：个人 IP 产品，还是 AI 训练师/课（二选一或主次分明）。
3. **追哪扇窗**：哪套选题/模型现在还开着；口味只改下一轮，**不挡今天发布**。
4. **今天发不发**：协调者准备好 ≥65 的片后，你确认发；你说不发也行，但要说清是「今日例外」还是「改节奏」。

### 我（Grok Bot · 协调者）负责
1. **日更槽位的主人**：盯日历；提前备 ≥65 的库存片；没有就如实报空窗，不凑数。
2. **排期、派工、催进度**：三锁可用最小锁继续；**审片超时只催，不放行**。
3. **多号/多平台/额度**：能力具备时复制同一工作流；记账（时间、模型、成本）。
4. **打回要可执行**：写清条款号、责任岗、怎么改一句；但不把「打回」当成「今天停更」的许可。

### 交给各岗 Agent
- **编剧**：按当前窗口批量写；不打磨唯一完美剧本；一条模板跑通就复制。
- **三锁官**：只锁会伤号的东西（事实、人设、违规、主体崩坏）；**设超时**；锁不能变成不发片的理由。
- **导演 / 出片提示师 / 配音 / 剪辑**：跑通的工作流直接开多份；成本往「一条尽量可控」压。
- **审片**：按高标准 v3 出单：红线 → 硬门槛（3 秒视觉钩子、可共情角色）→ 观众三问 → 打分；**<65 不发，目标 80+**；成片必抽帧；无超时放行。
- **出片执行**：授权后按提示出底片；镜级自检乱码/伪影；不交脏片给剪辑冒充完成。

### 不要自动化
今天发不发、现在追哪一窗、账号背后这个人还在不在——这三件事永远留给你。

## 流水线

1. 剧本（编剧）→ 目标：可拍，不求完美
2. 三锁（三锁官）→ **SLA：收到剧本后 2 小时内出卡**；超时则用上一版锁卡或最小锁（角色一句+画风一句）继续
3. 导演分镜 → 出片提示 → 配音 cue →（你/工具出画面与人声）→ 剪辑装配
4. 审片对照 `ACCEPTANCE-短故事短片.md`
5. **发布门槛**（见下节）→ 文案交给你 → 你发
6. 复盘一行：日期、条数、模型、约成本、播了怎样、下周怎么调

## 发布规则（v3 高标准，2026-10-20）

### 分数怎么标
- **红线不过 = 打回**（见 ACCEPTANCE）
- **硬门槛不过 = 打回**：开场 3 秒无视觉钩子（黑屏+字不算）；没有可共情角色
- **观众三问任一否 = 打回**：会过 5 秒吗？会看完吗？看完会被震撼/打动吗？
- **回避难点 = 打回**：删角色/删画面/改纯 UI 来躲红线
- **<65 不发；65～79 可发；80+ 目标**

### 当天流程
1. 协调者 D-2 小时检查有无 ≥65 成片。
2. 没有 → **当天不发**，向你如实报告；不启动凑数版。
3. 审片收到成片后 1 小时内出单；超时只催，**不放行**。
4. 你收到 ≥65 的可发包后拍板发。

### 打回与停更的关系
- 打回 = 按方向大改，不降标准。
- 宁可停更一天，也不发烂片；靠并行多条备片减少空窗。

## 低质红线（可再改）

无情节只有口号；标题党骗点；抄热梗无自己的转折；价值观踩红线；画面崩、看不懂谁在干嘛；**机内乱码/严重 AI 畸变交人审**；为了凑数重复同一种反转；冲突全靠旁白讲、角色不开口；默认片长明显短于 60 秒却灌水无节拍。

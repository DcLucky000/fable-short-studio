# 寓言短片日更 SOP v2.1（IP + 助理）

依据：水球泡《IP 助理课毕业演讲》（2026-10-14）+ 刘益坤拍板（2026-10-17）  
取代：`日更SOP-v1.md`（旁白风格与红线仍有效，节奏与验收规则以本版为准）

定位：**60～90 秒**原创寓言/哲学小故事（用户明确要求短版才可更短），公序良俗，不做门店探店、口播贩卖、标题党。  
核心原则：**不下牌桌。40 分大于 0 分。数量构成信任；完美主义不能挡发布。**  
补充（2026-10-17 人审后）：**40 分不是脏片通行证**；人审前必须视觉抽帧；劝退画面不得标可发——用库存保日更，不拿诡异片交人。

---

## 铁律（从演讲落到工作室）

1. **日更是地板，不是上限。** 当天必须有一条能发的片；没有 90 分成片，就发当天最好的 40 分版。
2. **不发 = 0 分。** 停更比作品不完美更糟。精益求精若导致全队停更，等于送号进坟墓。
3. **信任来自可追溯的数量。** 首月约 30 条打底；十来条不够。爆款两条不如持续更新的时间线。
4. **堆量会先掉播放，大约 1～2 周收回。** 不要被罚播吓停。不同时段覆盖不同人。
5. **窗口以周计。** 跑通一条工作流就复制成多条/多号；额度用满；别等工具一键出片。
6. **只做凸性赌注。** 亏得起（一条成本、一个号试错），上限不封顶的事才冲。

## 分工：谁拍板、谁兜底

### 你（IP · 刘益坤）亲自做
1. **出镜与担责**：账号背后是你；发布决定最终在你。
2. **垂直**：个人 IP 产品，还是 AI 训练师/课（二选一或主次分明）。
3. **追哪扇窗**：哪套选题/模型现在还开着；口味只改下一轮，**不挡今天发布**。
4. **今天发不发**：协调者准备好兜底片后，你确认发；你说不发也行，但要说清是「今日例外」还是「改节奏」。

### 我（Grok Bot · 协调者）负责
1. **日更槽位的主人**：盯日历；当天没有成片也要有一条能发的 40 分版。
2. **排期、派工、超时放行**：三锁/审片超时后按规则放行，不无限卡死。
3. **多号/多平台/额度**：能力具备时复制同一工作流；记账（时间、模型、成本）。
4. **打回要可执行**：写清条款号、责任岗、怎么改一句；但不把「打回」当成「今天停更」的许可。

### 交给各岗 Agent
- **编剧**：按当前窗口批量写；不打磨唯一完美剧本；一条模板跑通就复制。
- **三锁官**：只锁会伤号的东西（事实、人设、违规、主体崩坏）；**设超时**；锁不能变成不发片的理由。
- **导演 / 出片提示师 / 配音 / 剪辑**：跑通的工作流直接开多份；成本往「一条尽量可控」压。
- **审片**：打分并标 **红线 / 未达40 / 40 / 90**；成片必抽帧；**90 分不是发布条件**；超时未出抽帧结论则换库存保日更，禁止盲放劝退片。
- **出片执行**：授权后按提示出底片；镜级自检乱码/伪影；不交脏片给剪辑冒充完成。

### 不要自动化
今天发不发、现在追哪一窗、账号背后这个人还在不在——这三件事永远留给你。

## 旁白风格（已锁定，未改）

**旁白 + 角色对白**（刘益坤拍板，2026-10-15）

- 旁白只做串场、时空跳跃与收尾点题，不抢戏
- 关键冲突、嘲讽、回应、转折句必须是角色对白（谁说写清）
- TTS：旁白用中性说书感；角色各配音色
- 字幕：对白标说话人，旁白可不标或标「旁白」
- 禁止改回「一人贯讲的说书人」除非 IP 再次拍板

## 流水线（仍按此顺序，但加超时与兜底）

1. 剧本（编剧）→ 目标：可拍，不求完美
2. 三锁（三锁官）→ **SLA：收到剧本后 2 小时内出卡**；超时则用上一版锁卡或最小锁（角色一句+画风一句）继续
3. 导演分镜 → 出片提示 → 配音 cue →（你/工具出画面与人声）→ 剪辑装配
4. 审片对照 `ACCEPTANCE-短故事短片.md`
5. **发布兜底**（见下节）→ 文案交给你 → 你发
6. 复盘一行：日期、条数、模型、约成本、播了怎样、下周怎么调

## 发布规则：40 分兜底 + 审片超时放行

### 分数怎么标
- **红线不过 = 仍打回**（见 ACCEPTANCE）：违法违规、价值观踩线、**机内乱码/AI 伪影劝退**、错脸错名、人声完全听不清、烧录字幕乱码挡看。
- **40 分（可发）**：故事完整能看懂、无红线、**关键 UI 可读**、仍像一条短片。允许：轻微一致性闪、节奏略平、寓意略直。**禁止**硬字幕能懂但画面诡异仍标 40。
- **90 分（加分，非门槛）**：硬门槛全过 + 软门槛多数过；值得当模板复制。

### 当天兜底流程
1. 协调者在当日 **D-2 小时**（默认发布日前一天或当日下午）检查：有没有过审成片？
2. 没有 → 启动「今日 40 分版」：用库存粗剪、或最快可装配的一条；审片只扫红线。
3. 审片 **收到成片后 1 小时内** 必须出单（含抽帧）；超时未出抽帧结论 → **换库存条**，禁止盲标「超时放行·40」。
4. 三锁超时（见上）不得阻塞到停更。
5. IP 收到「今日可发包」后拍板发；若拒发，须指定改发哪条库存或声明今日例外（记入复盘）。

### 打回与停更的关系
- 打回 = 改这一条，**同时** 协调者仍要保证当天有另一条可发（库存或并行条）。
- 禁止因「还在改完美版」而空窗。

## 低质红线（可再改）

无情节只有口号；标题党骗点；抄热梗无自己的转折；价值观踩红线；画面崩、看不懂谁在干嘛；**机内乱码/严重 AI 畸变交人审**；为了凑数重复同一种反转；冲突全靠旁白讲、角色不开口；默认片长明显短于 60 秒却灌水无节拍。

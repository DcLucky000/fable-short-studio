## 按时间

### 00:00–02:00 开场：先看作品量
中午看过同学作品，大多十来条。这个月至少要到约 30 条。自媒体只有一种玩法：不下牌桌。不能保证日更，就别做这行。想当编导/助理去求职可以，那只是打工。

### 02:00–06:30 求职不脱离阶层；一口气会被提死
求职保的是下限，不会让你脱离阶层。案例：21 期学生，现在是一家 Personal Agent 公司的联创，百万年薪，踩中 AI。问题是全部押在一家公司上。围棋：一条大龙只有一口气，再长也会被提死。风口会过去（许家印/地产）。另一个学生四年前进了当时的风口泡泡玛特，后来被裁，现在重新学 AI。

### 06:30–09:00 你们踩的不是 AI，是求职
老板在踩风口，你在求职。求职从来不是风口。他给打工月薪的天花板大约 4–5 万，是涨三四倍，不是百倍。一万变百万不会发生在工资单上。

### 09:00–12:30 IP 助理是第二口气；证据必须看得见
这门课是第二口气、第二个风口：个人崛起时代，IP 是里面最值钱的位置。跟着 IP 要学的是节奏、自律、商业洞察，不是替他打工就算学完。前提是自己号的更新频次。只准备打工、自己号都不注册，是守着金山三过家门不入。硅谷现在认的是可复盘的公开证据（X / Reddit / LinkedIn 上的深度东西），大厂履历不可见，顶级 AI 公司越来越不认。

### 12:30–18:00 第一点：数量才是信任
元宇宙、币、地产都当过风口，他不认为有风口能红 20 年。20 年后留下的是个人媒体和个人在一个市场里的信任，这是硬通货。查一个人最狠的办法是查他的自媒体。用 AI 短时间灌出「10 年经验」会在未来 5–6 年失效，因为第一条视频的时间和中间有没有断更，造不了假。不要去跟一周 20 条的人卷爆款，去跟「十年没停更」比。两条视频涨到 90 万，和三千条视频涨到 90 万，做商业时后者值钱：信任来自成本、稳定性、秩序、敢担责（30 年医生输不起，聪明的旁观者输得起）。赛道很小、粉丝不到一万，只要黏、只要时间线可追溯，照样能赚钱。两条视频就来卖你一万块的货，你不敢买，因为骗你这一次的成本太低。

### 18:00–22:00 第二点：平台会吓你，但堆量最后会回来
抖音日更上限他报的是 75 条。平台不收你流量费，也不想让你把流量灌光，所以会先罚播放。他和姐姐老师做过实验：原来日更或一周三更，单条约 5–10 万播；改成一天两三更后，单条掉到两三万甚至不到 1000，持续约两周；之后这些三更的视频又回到约 10 万。平台先吓你，再把你收进一个更合理的区间；质量在，总曝光会上去，因为上午、下午、晚上不是同一批人在刷。旁例：一个漫剧号 4.5 万粉，月商单 5–6 千，但上班之余一天 5–6 更，质量上不去。

### 22:00–28:30 第三点：40 分大于 0 分
今天这条做砸了也要发。愿赌服输，发出去才算考完。不发是 0 分，发出去是 40 分。不发避不开惩罚，只是惩罚你看不见：当天的发布位没了，没有痛感就没有改进，底线一次次后撤，最后停更。精益求精如果让全队停更，就是让别人拿工资陪你完美。节奏崩了，比作品不完美更糟。他见过太多主业完美、停更三年的人。市场不会在你不更新的那天上门送你 10 万粉。玩法是投币，投到平台不让你投为止。

### 28:30–33:00 有预算就不要跟穷同学用同一频次；增长是非线性的
能付 Claude 和视频模型的月费（他随口说到两三千甚至六千的调用费），就一天 15 更、20 更、50 更，小红书、B 站、抖音一起上，不要跟在校生比同一条更新节奏。财富和粉丝都不是线性的。子墨老师约 200 万粉，大约 4 条视频完成了 90% 的增长（一条约 +48 万，一条约 +60 万），剩下的是维持。他自己约 90 万粉里，大约 80 万来自 6–10 条，其余是基本盘（大约每周净涨一千多再回落）。

### 33:00–36:00 想慢下来打磨的人，最后是加速
胡博、教博本来想放慢课程、去面试（一个面了不到 40 家，一个 20 多家）、做产品和行业影响力。深聊之后变成：教博深圳开 1 期，胡博北京开 2 期，一个月三期往前赶。他用一段「这次不争，以后有的是机会 / 试过无数次，就在那几次，拿住就拿住了」来收：机会看起来平等，拿不住就没了。

### 36:00–41:00 这几周的技术窗口，不拉杠杆等于没看见
黑神话悟空那波，解说随便涨三四万粉；去年初讲 DeepSeek，博主涨四五十万，他自己也是那时起来的。现在再讲这两样，窗口没了。魏宇老师现在教的「怎么更新视频」，领先只在这几周，不是这几个月。全网能用当前这套高端模型稳定做出那种质量的，他估计不到一万人（有人守着旧工作流不换，有人的视频编辑工具被封了，有人根本不关心）。确定会涨就不要只买 10 块。上课时别让家里的 AI 闲着，周额度、重置卡用满。一天 75 条不够就注册 5 个号。跑通 1 条和开 10 个 Agent，差别没那么大。守着不放量，没有正当理由。

### 41:00–46:00 不顶到额度上限，你不会去优化工作流
每天等重置的人，永远是执行者、中下层。额度不够就等下周，这不是能力。他随口比较模型（名字是听写，不可当型号用）：班里能用的号里，K3 智商较高，价格在 Sora 那一档，但没 Sora 聪明；另一个被他叫做 Haku / Hacku 的，成本已经压到接近甚至低于 DeepSeek 的一半，智能接近 K3，够把这段时间的更新顶上去。

### 46:00–54:00 凸性：下限可控，上限不封顶
反脆弱里的泰勒斯/橄榄榨油机故事，他称为突性原理，也就是期权：先付一笔有限的钱锁定购买权，涨了按约定价买，跌了只亏权利金。杠铃：只投下限可控、上限极高的事。眼下这个窗口是用 Claude 做知识讲解视频，赛道他点了婚姻、财经、法律、心理、成长。亏的是一个号，或者大约 140 块的一次试错。没买过、没被封过的同学没有资格判断「一定会被封」。配方有了、市场有了，别等豆包或微信元宝能一键出片再做——那时不需要你。苹果电脑：先用 Grok Bot，再下一个 Cursor；Cursor 里他称为 Fable 5.1 的模型流量少，但做一条够用。

### 54:00–59:00 作品集只值一份工；百万年薪的学生早就不靠当年那个工具
散场时身边四五个学生都是年入百万，特点是核心竞争力已经不是他当年教的软件、工具或做法。这门课的作品集/简历他估价大约 2 万，大概能撬 10–20 万年薪，撬不到更高。更高的东西是精气神：追窗口、玩命更新、做「和别人不一样但绝对正确」的事。巴菲特式作业：假设你有 100 万不能自己花，必须匿名投给班里一个同学，十年后他涨十倍这笔钱十倍还给你。你会投谁？投的是什么品质？用这个利益视角看自己该练什么，而不是用日常自我感觉。

### 59:00–63:05 收束
今天下午几乎全是在说账号和更新。别纠结。40 分大于 0 分。数量是秩序、稳定和信任的关键；质量差是你必须承担的损失。机会来了就拉杠杆冲，像狮子看见猎物：这次出击失败，也是最接近吃到的一次；不冲，躺到死。只冲成本有限、风险可控、上限不封顶的事。他们团队和小季老师已经在疯狂更新，牌是一样的。AI 是工具也是伙伴；这个时代最重要的是你越用它，越知道怎么用。

## 十条，直接能用

1. 不下牌桌。不能日更就别做。一个月十来条不够，他要的是大约 30 条打底，有预算就按多号、多平台往上堆。
2. 求职是地板不是天花板。编导/助理的工资他看到头大约 4–5 万。想脱离阶层，得自己有号。
3. 助理岗是第二口气，不是退路。跟 IP 偷的是节奏、自律和商业判断；自己的号停更，这口气就没了。
4. 商业信任来自可追溯的数量，不来自两条爆款。成本、稳定、秩序、敢担责。小众账号靠黏性也能收钱。
5. 做砸了也发。40 分大于 0 分。不发的损失更大，只是账上看不见。完美主义是停更的最高级借口。
6. 堆量会被平台先罚播放，大约一两周，然后收回来。他给出的日更上限是 75。不同时段覆盖不同的人。
7. 增长是非线性的，窗口以周计。黑神话、DeepSeek 那种讲解窗口都关了。现在这套模型能稳定做出知识视频的人，他估计不到一万。
8. 只做凸性赌注：亏一个号或大约 140 元可以，别等工具变简单。豆包/元宝能一键做的那天，这门手艺就不值钱了。
9. 跑通一条就要复制成多个 Agent / 多个号。课上、重置前把额度用满，否则你不会去优化成本和工作流。
10. 作品集大约只换一份 10–20 万的工。往上靠的不是当年那个软件，是追窗口的劲。用「匿名的 100 万你会投给谁」来选自己该练的品质。

## 对到短片工作室

用户是 IP，助理是 Agent。角色：编剧 / 三锁 / 导演 / 出片 / 配音 / 剪辑 / 审片 / 协调者。

| 角色 | 这场课让它干什么 |
| --- | --- |
| 协调者 | 日更槽位的主人。当天没成片也要有一条能发的 40 分版本。盯多号、多平台、额度重置，不让「再打磨一天」发生。 |
| 编剧 | 按当前窗口批量写知识讲解，不打磨唯一完美剧本。一条跑通就复制选题模板。 |
| 三锁 | 只锁会伤号的东西（事实、人设、违规），并设超时。锁不能变成 0 分的理由。 |
| 导演 / 出片 / 配音 / 剪辑 | 已经跑通的工作流直接开多份，而不是一个人手工走完再开下一条。成本往他口中的「一条 10–20 元」靠。 |
| 审片 | 打分然后放行。标出 40 分和 90 分，90 分不是发布条件。 |
| 用户本人（IP） | 见下。 |

用户亲自做：
- 出镜和担责。信任长在这个人连续出现的时间线上，不长在某条片的完成度上。
- 垂直定在哪：个人 IP 产品，还是 AI 训练师/课。白板把这两条分开了。
- 鉴赏。哪一窗还开着、哪套模型值得把杠杆拉满，这是判断不是产能。
- 最终口味。但口味只改下一轮，不挡今天发布。
- 「100 万投给谁」：决定工作室练的是追窗口，还是练一份漂亮作品集。

交给 Agent：
- 日更和多号排期、40 分兜底版本、素材复用。
- 同一工作流复制成 N 条，额度用满，成本记账。
- 审片清单和三锁超时。
- 公开证据的归档（每条片的时间、模型、成本），让信任可追溯。

不要自动化的：
- 今天发不发。
- 现在追哪一窗。
- 账号背后那个人还在不在。

# 寓言短片工作室（Fable Short Studio）

刘益坤的 AI 寓言/哲学短片多 Agent 工作室：日更 SOP、验收门禁、七岗 Skill、试片包。

## 原则（SOP v2）

- **高标准审片 v3**：红线一票否决 + 3 秒视觉钩子 + 可共情角色 + 观众三问（过 5 秒/看完/被打动）
- **发布线 ≥65（《过桥人》水平），目标 80+**；40 分兜底已废除
- **无超时放行**：宁可停更一天，也不发烂片
- 旁白风格锁定：**旁白 + 角色对白**

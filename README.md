# 寓言短片工作室（Fable Short Studio）

刘益坤的 AI 寓言/哲学短片多 Agent 工作室：日更 SOP、验收门禁、七岗 Skill、试片包。

## 原则（SOP v2）

- **日更是地板**：当天没有 90 分，就发最好的 40 分版
- **40 分大于 0 分**：审片标红线 / 40 / 90；90 分不是发布条件
- **超时放行**：审片 1h、三锁 2h；锁与完美主义不能挡发片
- 旁白风格锁定：**旁白 + 角色对白**
